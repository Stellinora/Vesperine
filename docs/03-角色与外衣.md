# 03 · 角色与外衣

> 角色是「事」，是主体穿上的外衣。记忆属于主体，角色只是访问视角。

## 一、角色的组成

```
RoleCard (身份/外衣) {
    id
    name            // "运维工程师" / "私人助理" / "生活态"
    tools           // 这个角色能用什么工具
    autonomy        // 这个角色的授权级别
    wakeup          // 这个角色被什么唤醒
    style           // 这个角色的交互风格
    goals           // 这个角色的职责目标
    memory_view     // 这个角色如何看待记忆
}
```

**角色不是子 Agent，是主体的「工作模式」。** 它不拥有记忆，只拥有「回想方式」。

---

## 二、工具不通用——硬边界

工具绑定**角色卡**，不绑定人。

- **工具不能跨角色调用**——运维角色不能用助手角色的 `fs.read` 读私人文件
- **权限不能跨角色继承**——运维角色的集群权限，在助手角色下无效
- **角色切换 = 工具集完全重载**——不是叠加，是替换

> 因为角色卡本身就不跨基座（见 [01 本体论](01-本体论.md)），工具实际上**连基座都不会跨**。这是比早期文档更硬的一层。

**唯一的例外：主体级的「元能力」**——切换角色、请求跨角色记忆、自我内务。这些属于**基座（本真层）**，不属于任何角色卡。详见 [04 唤醒与运行](04-唤醒与运行.md)。

---

## 三、记忆访问规则（三层）

记忆挂在基座上；角色卡通过「视角」访问它。

```
enum MemoryAccess {
    // L1: 当前角色的记忆——默认可见，自动召回
    SameRole,

    // L2: 共享层（主体级记忆）——默认可见，但需相关性触发
    Shared,

    // L3: 其他角色的记忆——默认不可见，需主动发起
    CrossRole {
        from: RoleCardId,
        to:   RoleCardId,
        reason: String,     // 必须说明为什么需要
    },
}
```

| 层 | 可见性 | 触发 |
|---|---|---|
| L1 本角色 | 默认可见 | 自动召回 |
| L2 共享层 | 默认可见 | 相关性触发 |
| L3 跨角色 | 默认不可见 | 主动发起 + 说明理由 + 可审计 |

---

## 四、跨角色召回

**默认不可见。** Agent 在角色 A 下，检索默认只走 A 的记忆区 + 共享层。

**主动发起。** 触发条件（启发式）：

- 当前情境与某角色的历史经历在语义上高度相似
- 当前问题涉及其他角色的职责域
- 用户明确暗示「你之前好像处理过类似的」
- 主体级目标需要跨角色协调

**用户可感知。** 跨角色联想是外显的：

```
运维角色下，Agent 说：
  "这让我想起之前帮您处理家庭网络时的类似问题——
   虽然场景不同，但排查思路可能通用。"
```

用户知道 Agent 跨越了角色边界，可以选择阻止。

**动作序列：**

```
1. Agent 生成「跨角色召回请求」
2. 请求带 reason（为什么需要）
3. 系统检查 access policy
4. 允许 → 召回相关片段，注入当前上下文
5. 记录这次跨角色访问（可审计）
```

---

## 五、底色的位置

底色的后台循环（走神/整理/自省）不属于任何角色卡。切卡时只重载**对外执行工具**，底色内务照常运行。详见 [04 唤醒与运行](04-唤醒与运行.md)。

---

## 六、角色切换的运行时

```
async fn switch_role(current: RoleCard) -> RoleCard {
    // 卸载当前角色的所有对外能力
    unload(current.tools)
    autonomy = none
    wakeup_sources = []

    // 加载新角色
    next = base.role_cards.get(target)
    tools          = next.tools
    autonomy       = next.autonomy
    wakeup_sources = next.wakeup

    // 记忆视角切换（不是记忆切换）
    memory_view = MemoryView::for(next)

    // 主体身份不变；主体记忆不变，只是访问视角变了
    // 底色层继续运行
}
```

**关键：切换的是「对外执行」与「记忆视角」，不是「我是谁」。**
