# 08 · 人类学的仿与不仿

> 仿人类学——但只仿「好的那一部分」。

## 一、应该仿的

| 人类特征 | 系统对应 |
|---|---|
| 角色边界 | 工具/权限/记忆的硬隔离（卡绑基座） |
| 情境记忆 | 记忆按角色分区，按情境召回 |
| 主动回忆 | 跨角色记忆需主动发起，非自动 |
| 外显联想 | 跨角色调用对用户可见、可阻止 |
| 遗忘曲线 | 按重要度/时效衰减 |
| 情绪权重 | 高影响事件记得更牢（emotion_weight） |
| 睡眠巩固 | 后台整理、摘要、模式挖掘 |
| 元认知 | 知道自己知道什么、不知道什么 |
| 社会边界 | 人之间硬隔离，通过外显渠道通信 |
| 注意力有限 | 汇报有打扰预算 |
| 承诺与责任 | 角色有职责目标，需履行 |
| 信任演化 | autonomy 随表现调整 |

---

## 二、不应该仿的

| 人类缺陷 | 为什么不仿 |
|---|---|
| 虚假记忆 | AI 记忆必须可溯源 |
| 确认偏误 | 检索应保持中立 |
| 情绪失控 | 情绪只作为权重，不驱动行为 |
| 认知偏见 | 不应继承人类的系统性偏见 |
| 遗忘创伤 | 重要事件不应因「痛苦」而丢失 |
| 社会操纵 | 不利用人类心理弱点 |
| 成瘾设计 | 不制造依赖 |

---

## 三、一句话

**仿边界、仿情境、仿遗忘与巩固、仿信任演化；不仿偏见、不仿虚假、不仿操纵。**

拟人性来自「在矛盾中取舍」，不是来自「复制人类的缺陷」。
