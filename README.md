# Vesperine · 数字主体

> **一个数字主体，多套角色外衣。**

Vesperine 是一套**分离式 Agent 架构的理论框架**。

- 它不是产品原型，是**参考实现的理论篇**。
- 它证明的不是「能不能做」，是「应该怎么做」。
- 产物不是「能跑的系统」，是**可执行的架构描述**。
- 价值在架构的正确性与可解释性，不在代码量。

---

## 定位

**豁免：投入、回报。**

**不豁免：安全、权限、隔离、审计、身份、架构正确性、可维护性、可扩展性、完整度。**

当前状态：**理论阶段**。本仓库只承载文档，不落地代码、不选技术栈。

> **路线状态**：00–11 是主线理论篇；12 是极简路线提案，尚未取代主线。若采纳 12，01–04、06、08 需要封存或重写。

---

## 一句话核心

不是「多个 Agent 共享记忆」，而是**一个「人」，穿着不同的角色外衣**。

- 主体是「人」：一份身份、一份记忆、一个人格、一条连续的生命线
- 角色是「事」：工具、权限、唤醒源、交互风格、职责
- 记忆属于主体，角色只是访问视角
- 切换角色 = 换工作模式，不是换人

## 与其他项目的关系

Vesperine 是**底座理论**。它之上可承载多个**项目**（例如「赛博生命」「AI 助手」），每个项目是「基座（人）× N + 角色卡」的一套部署。项目之间共享基础设施，不共享「人」。
